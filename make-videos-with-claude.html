Make videos with Claude

Last updated 22 November 2026

You can make a full animated video with voice, music and sound effects by describing it to Claude in plain words. You don't need an animation studio, and you don't need to know how to code.

Both videos below were made this way. Claude wrote the script, drew every character and scene in code, added the voiceover and sound, and rendered the final MP4. This page shows what to install and what to type to make your own.

The two example videos

Both are vertical (9:16), the shape used for Reels, Shorts and TikTok.

How it works

Claude doesn't "film" anything. It writes a small web project with Remotion, a free tool that turns code into video. Every frame is a web page, and Remotion records the frames into an MP4.

Because the whole video is code, every change is quick. You say "make the title bigger" or "use brighter colours", and Claude edits the code and renders it again.

Set up: one prompt

You only install one thing yourself: Claude Code, the version of Claude that can create files and run programs on your computer. Get it from claude.com/download and use the desktop app's Code tab.

Claude subscription needed. Claude Code isn't part of the free Claude plan. You need a paid plan: Pro, Max or Ultra (see claude.com/pricing). Everything Claude installs for you below is free.

Then open an empty folder in Claude Code and paste this prompt:

I want to make video reels using Claude. Check my setup and install all necessary tools to achieve this.

Claude checks what is already on your computer and installs what's missing. It asks before each install, so read each request and click Allow. This takes about 10 to 20 minutes.

What Claude installs

Your list may differ a little, depending on what you already have. For the example videos, Claude set up these tools:

ToolWhat it's for
RemotionTurns code into video. Claude builds every scene with it.
Node.js, Python and gitThe programs that Remotion and the other tools run on.
FFmpegJoins, trims and compresses audio and video.
whisper-ctranslate2Turns speech into text, for subtitles and captions.
yt-dlpDownloads video clips you have the right to use, for example your own uploads.

Claude can also add Remotion skills. A skill is a set of instructions that teaches Claude one job well, such as building, previewing or rendering a video. For a voiceover, Claude can set up Kokoro, a free voice that runs on your own computer with no account. If Claude doesn't offer these, ask for them.

Make your first video

Claude subscription needed. Every step below runs in Claude Code, so it needs a Pro, Max or Ultra plan. Pro and Max have a five-hour and a weekly usage limit. A long video session can reach the limit, so you may have to wait for it to reset before you carry on.

  1. Make an empty folder, for example My Videos, and open it in Claude Code.
  2. Describe your video. Say what it's about, how long it should be, its shape, and the feel you want. For example: 
    Make a 45-second landscape (16:9) animated video that explains how plants make food from sunlight. Use friendly cartoon characters, a calm voiceover, light background music and soft sound effects. Use Remotion.
  3. Claude writes a script and shows it to you. Read it and say what to change.
  4. Claude builds the scenes and opens a preview in your browser. Watch it.
  5. Ask for changes in plain words: "make the title bigger", "slow down scene 3", "use a warmer voice".
  6. When you're happy, say "render it". Claude exports the MP4 into an out folder.

A video like the examples takes about one to two hours of back-and-forth the first time, mostly spent on changes. Rendering one minute of video takes a few minutes on a normal laptop.

How the example videos were built

Here's what Claude made for the two example videos, so you know what to expect:

  • Scenes as code. Each scene is its own file. The first video has six (A1.tsx to A6.tsx), and Remotion plays them in order at 30 frames a second.
  • Characters drawn in code. Every shape and character was drawn by Claude as code. No image files were used for the artwork.
  • Voiceover. Claude wrote the narration line by line, made each line with Kokoro (voice af_heart), and timed the animation to match the speech.
  • Sound effects. Claude synthesised the pops and whooshes with a short Python script instead of downloading them.
  • Music. Free tracks by Kevin MacLeod, mixed under the voice with FFmpeg.
  • Final export. Remotion rendered the full-HD MP4, and FFmpeg compressed a smaller copy for this page.

Tips

  • Be specific about the feel. "Playful, bright colours, bouncy motion" works better than "make it nice".
  • Change one thing at a time. Small requests give cleaner results than a long list.
  • Use free music and credit it. Tracks from incompetech.com are free if you credit the artist.
  • Check the licence. Remotion is free for individuals and teams of up to three. Larger companies need a company licence.
