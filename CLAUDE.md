# learning-today: notes for Claude

Two parts in one repository (see README.md):
- the static site learning-today.com (root HTML pages, `theme.css`, `site.js`), published by GitHub Pages from `main`;
- the Batch 91 Portal in `portal/` (Next.js + Supabase on Vercel), with its own README, SETUP and AGENTS.md.

## Student websites gallery
`student-websites.html` is generated by scripts that live outside this repo (on the owner's computer, next to the raw chat export). **Before regenerating it, read `docs/student-gallery.md` and make the generator follow it.** After regenerating, run:

```bash
node tools/check-student-gallery.mjs
```

and only commit when it prints `OK`. Fix problems in the generator, not by editing the HTML by hand.

## Other rules
- Never commit the WhatsApp chat export, `.env` files or keys.
- After changing `theme.css` or `site.js`, bump the `?v=` date on every page that links it.
- Portal database changes go in a new file in `portal/supabase/migrations/` that says at the top whether to run it before or after merging; never edit one that has already run.
- Portal tests: `cd portal && npm test` (unit, database and browser; see portal/README.md).
